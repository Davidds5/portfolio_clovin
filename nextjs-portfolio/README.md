# Portfólio David Silva (Clovin DEV) — Next.js 15 & Tailwind CSS

Portfólio minimalista editorial de alto contraste inspirado em [Nathan Paranhos](https://nathan-paranhos.com.br/).

---

## 🎨 Sistema de Design

- **Tipografia:**
  - *Títulos & Expressões:* `Playfair Display` (Serifada elegante com itálicos expressivos).
  - *Corpo do Texto:* `DM Sans` (Sans-serif geométrica de alta legibilidade).
  - *Tags & Metadados:* `JetBrains Mono` (Monospaçada técnica com tracking expandido).
- **Paleta de Cores:**
  - *Canvas Principal:* `#ffffff`
  - *Canvas Suave:* `#f8f8f6`
  - *Linhas & Bordas:* `#e5e5e0` (1px Hairline suíço)
  - *Texto Principal:* `#090909` (Preto/chumbo de alto contraste)
  - *Texto Secundário:* `#595959`
  - *Acento Vibrante:* `#f15a24` (Laranja marcante para números, status dot, badges e hovers)

## 🚀 Como Executar Localmente

1. Entre no diretório do projeto:
   ```bash
   cd nextjs-portfolio
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra no navegador:
   ```
   http://localhost:3000
   ```

## 📦 Como Fazer Deploy

### Vercel (Recomendado para Next.js)
1. Conecte o repositório na [Vercel](https://vercel.com).
2. Defina a pasta raiz do projeto como `nextjs-portfolio` (Root Directory).
3. O deploy será gerado automaticamente.

### GitHub Pages (Versão Estática Imediata)
A versão estática equivalente e 100% autônoma já está pronta no arquivo `index.html` na raiz do repositório, pronta para ser servida diretamente pelo GitHub Pages em `https://davidds5.github.io/portfolio_clovin/`.
